# 🚨 Offline AI Chatbot — Java Swing + Python

**A fully offline AI chatbot built to solve real-world problems.**

## Overview
I wanted to integrate AI into a Java chatbot. The deeper I went, the more real the challenges became:

- ⚙️ Python backend was stuck on version **3.7**, while OpenAI’s API needed **3.11**  
- 🔑 Fixed the environment, only to face missing libraries, invalid API keys, and rate limits  
- 💸 Credits ran out — relying on cloud APIs meant relying on limits  

That’s when I asked myself:  
> “Why depend on servers when I can make AI run locally?”  

## Solution
- Rebuilt the backend from scratch  
- Tested Hugging Face models: *DialoGPT* and *Gemini* — both failed  
- Integrated **Dolly Mini / MiniLM**, a lightweight local model  

✅ Instantly working offline  
✅ No API keys or cloud dependencies  
✅ Fast, accurate, and completely free  

## Features
- Built with **Java Swing** (GUI) + **Python** (backend)  
- Runs **Hugging Face model locally**  
- Works **anywhere, anytime** — no internet required  

## Development
- Duration: 4–5 days (~16–18 hours)  
- Focus: revising Java-Python integration, debugging, and testing   

## Reflection
This wasn’t just a coding task — it was a real-world problem solved.  
Sometimes, **building smarter matters more than building bigger.** ⚙️
