# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it **privately** so it can be addressed promptly.  
You can contact me at: **sohamgoswami700@gmail.com**  

Please include:  
- A detailed description of the issue  
- Steps to reproduce the vulnerability  
- Any potential impact  

Do **not** open a public GitHub issue for security vulnerabilities. This ensures the issue is not exposed to malicious actors.

## Supported Versions

This project is actively maintained and security updates will be applied for the **latest version** of the chatbot. Older versions may not receive security fixes.

## Security Best Practices

- Always keep your Python and Java environments up to date.  
- Do not share your API keys or secrets publicly.  
- Ensure any third-party libraries used are up to date and from trusted sources.  

## Acknowledgements

Thank you to anyone who reports vulnerabilities responsibly — you help keep this project safe and secure.
